# entities/

This directory holds all graph node files (entities), organized into
subdirectories that mirror the community hierarchy described in
`docs/GRAPH_CONVENTIONS.md`.

Each subdirectory represents a domain or sub-domain and SHOULD contain a
`_community.yaml` (see `templates/_community.yaml.template`).

Currently empty — this is scaffolding ahead of content migration from
`SCHEMA_SPEC.md`. See `README.md` for the graduation roadmap.
