# relationships/

Cross-cutting relationship definitions that span multiple domains and don't
belong under a single `entities/<domain>/` subtree.

Files here follow the same frontmatter convention as entity nodes
(see `docs/GRAPH_CONVENTIONS.md`), using `type: Relationship` (PascalCase — see
docs/GRAPH_CONVENTIONS.md#type-casing-convention), already declared in
`schema/schema.yaml`.
